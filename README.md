# Floor Calc Pet Project
Простой сервис: калькулятор стоимости укладки напольного покрытия.
Заказчик: внутренний пилот.
## Артефакты проекта

| Артефакт | Описание | Где лежит |
| --- | --- | --- |
| Требования | Функциональные требования с ID и приоритетами | `requirements.md` |
| Матрица трассируемости | Связь требований с артефактами дизайна и тест-кейсами | `traceability-matrix.csv` |
| Чек-лист валидации | Правила проверки целостности артефактов | `VALIDATION.md` |
## Артефакты проекта

В репозитории зафиксированы ключевые артефакты системного анализа для модуля расчёта НДС:

| Артефакт | Назначение | Где лежит |
| --- | --- | --- |
| Требования | Функциональные требования с ID, приоритетами и источниками | `requirements.md` |
| Матрица трассируемости | Связь требований с тест‑кейсами и статусами реализации | `traceability-matrix.csv` |
| Тест‑кейсы | Сценарии проверки требований (базовые и альтернативные) | `test-cases.md` |
| Чек‑лист валидации | Правила проверки целостности и качества артефактов | `VALIDATION.md` |

Этот набор позволяет контролировать полноту требований, отслеживать покрытие тестами и поддерживать прозрачность изменений через Git.
