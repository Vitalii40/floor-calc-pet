# Чек-лист валидации артефактов

## Требования (requirements.md)
- [ ] У каждого требования есть уникальный ID в формате PREFIX-NNN (например, VAT-001).
- [ ] Для каждого требования указан источник и приоритет.

## Матрица трассируемости (traceability-matrix.csv)
- [ ] В каждой строке заполнено требование и хотя бы один связанный артефакт (design/test).
- [ ] Статус указан (In Progress/Done/Blocked).
- [ ] Нет дубликатов requirement_id.

## Общие правила
- [ ] Все файлы в UTF‑8.
- [ ] Имена файлов без пробелов и спецсимволов.
