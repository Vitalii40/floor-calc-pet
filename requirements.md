# Требования к функционалу расчёта НДС

## Требование VAT-001
**ID:** VAT-001  
**Тип:** функциональное  
**Описание:** Система должна поддерживать расчёт НДС для каждой позиции заказа. Ставка НДС берётся из справочника и может быть переопределена на уровне заказа.  
**Приоритет:** высокий  
**Источник:** бизнес-требования заказчика

## Требование VAT-002
**ID:** VAT-002  
**Тип:** функциональное  
**Описание:** В отчёте по заказу должна отображаться отдельная строка «Сумма НДС» и «Итого с НДС».  
**Приоритет:** средний  
**Источник:** UX/UI спецификация

- **VAT-003**: Для товаров категории «влагостойкие покрытия» НДС не начисляется, для «обычных» — по ставке 20%, для «импортных» — по ставке 10%.  
  *Приоритет: Высокий*  
  *Источник: Бизнес-требования (категоризация товаров)*
